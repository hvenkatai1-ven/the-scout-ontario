The brief, as I read it

A day-planning tool first, a discovery feed second. Trend is only useful here if it resolves into a route you can actually shoot: what is peaking, when the light is on it, and how far it is from the last stop.

Set in Broadsheet, so the app reads as a daily paper for the province — ranked ledger, serif chrome, cyan for anything you can touch, magenta kept for the one thing that is peaking. Photographs print as newsprint dot screen.

Light times are a fixed Sept 26 schedule for the Grand River valley; the countdown runs live off your clock.
